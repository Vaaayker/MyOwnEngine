# firstrep
Пробний репозиторій для розуміння сутності гітхабу на початковому рівні: issue -> branch -> pr -> merge. Репозиторій націлений на те, щоб зрозуміти загальний воркфлоу та проджект менеджмент. Освоїти навички для використання: дошки планувань, розподілу задач, виконаня задач в окремих гілках, запроси на злиття та саме злиття.
